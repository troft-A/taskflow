# 🚀 TaskFlow

> **TaskFlow** est un projet étudiant d’application web de gestion de tâches. Il a été pensé pour aider un binôme ou un étudiant à noter ses tâches, suivre son avancement et identifier ses priorités en un coup d’œil.

---

## 📌 Philosophie du projet

> **L’IA propose, c’est nous qui décidons.**  
> Les outils d’IA peuvent aider à trouver des idées et à formuler des propositions, mais les choix finaux et leur vérification appartiennent au binôme.

---

## 🎯 Objectifs

- **Socle clair** : Définir un ensemble fonctionnel solide doté de critères d’acceptation vérifiables.
- **Cycle de vie complet** : Permettre à l'utilisateur de créer, consulter, modifier, terminer et supprimer ses tâches.
- **Persistance locale** : Prévoir une sauvegarde automatique pour retrouver ses tâches d'une session à l'autre dans le même navigateur.
- **Légèreté et simplicité** : Garder une base épurée, parfaitement adaptée à un projet étudiant et à une réalisation progressive.

---

## 🛠️ Technologies prévues

La réalisation de l'application est prévue en technologies web natives :
- **HTML5** / **CSS3** / **JavaScript (Vanilla)** — *Sans framework obligatoire*.
- **`localStorage`** — *Pour la conservation des données dans le navigateur*.
